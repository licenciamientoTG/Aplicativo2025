🚨 Principales Problemas Detectados en el Sidebar Actual
Problema Impacto UX Ejemplo Real en el Código Solución Propuesta
Duplicidad Alta Confusión de usuarios, pérdida de tiempo y reportes inconsistentes. /operations/sales_day_turn aparece en TG3-Operaciones, Comercial y Operaciones. Mantener una sola ruta centralizada en Comercial y Ventas con permisos compartidos.
Módulo Espejo Redundancia del 90% del menú. El encabezado TG3-Operaciones (permiso 62) es una copia casi idéntica de Comercial › Reportes (mismo permiso 62). Eliminar TG3 como módulo separado y consolidar todo en Ventas y Comercial.
Dispersión de Combustible El usuario navega 4 menús para una sola operación. Inventarios en Abastos, análisis en Contabilidad, horas sin gas en Dirección y compras en Contabilidad. Crear el pilar unificado Combustible y Abastos con submenús temáticos.
Nomenclatura Débil Enlaces crípticos o técnicos. Rutas como /income/test_v3 ("Conciliar"), /supply/bulkUpload2 ("Pendiente (Nuevo)") o abreviaturas como "Vta Sem x Zona". Nombres claros orientados a la función real: "Conciliación Bancaria", "Carga Masiva XML", etc.
Submenús Genéricos Fatiga visual. El usuario ve "Reportes" y "Herramientas" repetido 7 veces. Abastos tiene Reportes/Herramientas, Administración tiene Reportes/Herramientas, etc. Submenús específicos: "Inventarios", "Logística y Recepciones", "Precios y CRE".
Ausencia de Buscador Con ~140 enlaces, encontrar una pantalla requiere memorizar la ruta interna. El usuario debe recordar si "Facturas ControlGas" está en Ingresos o Contabilidad. Buscador reactivo en la cabecera del sidebar con filtro instantáneo en JS.
💡 Principios del Nuevo Diseño

1. Organización por Proceso: Los usuarios no piensan en "controladores de Symfony o PHP", piensan en sus tareas diarias: vender, cuadrar inventario, conciliar bancos o pagar a proveedores.
2. Respeto a los Permisos: La nueva estructura conserva al 100% las directivas authorized(id) existentes. Si un usuario no tiene permiso, la opción o el grupo simplemente no se renderiza.
3. Profundidad Controlada: Máximo 2 niveles de anidación (Grupo ▸ Submenú) con acordeones auto-excluyentes o fluidos.
4. Buscador en el Sidebar: Permite escribir palabras clave (ej. "tarjeta", "merma", "arqueo") y abre de inmediato la sección correspondiente.

Snippet Recomendado para el Buscador JS
// Buscador Reactivo para el sidebar (pegar en sidebar.html)
document.getElementById('sidebarSearchInput')?.addEventListener('input', function(e) {
  const term = e.target.value.toLowerCase().trim();
  const groups = document.querySelectorAll('.sidebar-nav .sidebar-item');
  
  groups.forEach(item => {
    const text = item.textContent.toLowerCase();
    const hasMatch = term === '' || text.includes(term);
    item.style.display = hasMatch ? '' : 'none';
    
    // Si hay coincidencia y tiene submenú colapsado, desplegarlo
    const dropdown = item.querySelector('.sidebar-dropdown');
    if (dropdown && term !== '' && hasMatch) {
      dropdown.classList.add('show');
    }
  });
});
