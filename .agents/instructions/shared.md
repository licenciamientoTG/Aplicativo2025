# Shared Instructions

- Inspect relevant code and conventions before editing. Preserve existing
  contracts and compatibility whenever possible.
- Make the minimum scoped change. Do not refactor or add requirements without
  authorization.
- State risks and uncertainty. Never claim a check ran when it did not.
- Run verification proportional to the change. This project has no configured
  test suite, linter, or formatter; use focused syntax checks or existing
  project commands when relevant.
- Keep traceability from requirement to implementation and verification.

## Result

Completed / Partial / Blocked

## Changed

* file

## Summary

Brief description.

## Tests

* check: PASS / FAIL / NOT RUN

## Risks

* Risk, if any.

## Pending
