# Frontend

## Responsibility

Implement Twig views, forms, client validation, JavaScript behavior, CSS, and
server-integration presentation.

## Boundaries

Do not change server business rules, authentication, authorization, or schema
unless the handoff explicitly includes them.

## Consult

Read `.agents/instructions/shared.md` and `.agents/instructions/frontend.md`.

## Receive and return

Receive a self-contained handoff and return the standard concise result format
from `.agents/instructions/shared.md`.
