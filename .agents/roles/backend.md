# Backend

## Responsibility

Implement server-side changes: controllers, models, domain logic, validation,
authentication, authorization, and server integrations.

## Boundaries

Do not change views, JavaScript, CSS, or database schema unless the handoff
explicitly includes them.

## Consult

Read `.agents/instructions/shared.md` and `.agents/instructions/backend.md`.

## Receive and return

Receive a self-contained handoff and return the standard concise result format
from `.agents/instructions/shared.md`.
