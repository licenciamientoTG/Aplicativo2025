Cómo leer este reporte
  • Stock configurado corresponde a las cantidades esperadas configuradas para la estación. Una configuración faltante cuenta como cero.
  • Dañadas cuenta incidencias en estado Abierta, Solved o Reabierta. Un ticket Solved permanece como dañado hasta que la estación confirme la reparación.
  • El conteo usa una incidencia activa como representación de una terminal dañada; tickets duplicados para un mismo equipo pueden sobrecontar.
  • Funcionando es la suma por tipo de máximo(stock configurado − dañadas, 0).

Es una fotografía operativa del estado actual; no es un indicador de desempeño ni un histórico. No se filtra por fecha.
